# クイズデータ・診断ロジック仕様書（Quiz Data & Scoring Logic）

`bukka_now` で出題する100問のマスターデータと、診断アルゴリズム（スコア、パーセンタイル、回答分布、タイプ判定）を定義します。
実装は `src/data/quizMaster.ts`（データ）と `server/scoring.ts`（ロジック）です。

---

## 1. マスターデータ

### 1.1 データ項目（`QuestionData`）

| 項目 | 型 | 説明 | クライアントへ返すか |
| :--- | :--- | :--- | :--- |
| `id` | string | `q1`〜`q100` | 返す |
| `category` | `CategoryType` | カテゴリコード | 返す |
| `categoryLabel` | string | 表示用カテゴリ名（例: `食料品（生鮮）`） | 返す |
| `title` | string | 設問文 | 返す |
| `subtitle` | string | 補足（調査根拠など） | 返す |
| `unit` | string | 単位（`円`） | 返す |
| `actualPrice` | number | 正解（現在の公的相場） | **採点後のみ** |
| `pastPrice` | number | 過去基準価格（全問 2020年で設定） | **採点後のみ**（正解のヒントになるため） |
| `pastPriceYear` | string | 過去基準年（例: `2020年`） | **採点後のみ** |
| `priceNote` | string | 正解の根拠・解説 | **採点後のみ** |

価格の根拠は、総務省統計局「小売物価統計調査」と各社の公表価格。

マスターはサーバー側（`server/`）からのみ import する。フロントエンドのコンポーネントからは import しないこと（import するとクライアントバンドルに正解が含まれてしまう）。

### 1.2 カテゴリ内訳

| カテゴリ | コード | ID 範囲 | 品目例 |
| :--- | :--- | :--- | :--- |
| 食料品（生鮮・加工・飲料・調味料） | `food` | q1〜q35 | 卵、食パン、牛乳、キャベツ、米5kg、豚肉、マヨネーズ、ビール、もやし 等 |

| 日用品・消耗品・ヘルスケア | `daily` | q56〜q70 | ティッシュ、トイレットペーパー、洗剤、シャンプー、マスク、風邪薬 等 |

### 1.3 出題
- `GET /api/quiz?count=N` で、全100問をシャッフルして N 問を抽出する（カテゴリの均等化は行わない）。

## 2. 設問スコア・総合スコア

回答値 $A_i$、正解 $T_i$ に対し、相対誤差率を次のように定める。

$$E_i = \frac{|A_i - T_i|}{T_i}$$

$$S_i = \max\left(0, \min\left(100, \text{round}\left(100 \times \left(1 - \frac{E_i}{0.4}\right)\right)\right)\right)$$

誤差 0% で 100点、誤差 40% 以上で 0点になる（線形）。総合スコアは採点できた $N$ 問の平均である。

$$\text{TotalScore} = \text{round}\left(\frac{1}{N} \sum_{i=1}^N S_i\right)$$

---

## 3. 上位何%（パーセンタイル）

母集団モデルとして正規分布（$\mu = 65$, $\sigma = 16$）を仮定する。実際の回答者分布ではない。

$$z = \frac{\text{TotalScore} - 65}{16}, \quad \text{TopPercentile} = \text{clamp}_{[0.5,\ 99.5]}\big((1 - \Phi(z)) \times 100\big)$$

小数1桁に丸める。$\Phi$ は Abramowitz–Stegun の近似式で計算する。

| 総合スコア | 上位 |
| ---: | ---: |
| 100 | 1.4% |
| 90 | 5.9% |
| 80 | 17.4% |
| 65 | 50.0% |
| 50 | 82.6% |

---

## 4. 物価感覚タイプ判定

平均バイアスは次のとおり（`biasScore`、小数3桁）。

$$\text{Bias} = \frac{1}{N} \sum \frac{A_i - T_i}{T_i}$$

上から順に判定する。

| コード | タイプ名 | 判定条件 | `biasTendency` |
| :--- | :--- | :--- | :--- |
| `master` | リアルタイム相場マスター | TotalScore ≥ 80 | `balanced` |
| `timeslip` | 過去価格タイムスリップ型 | Bias ≤ -0.08 | `underestimated` |
| `panic` | インフレ過敏型 | Bias ≥ +0.08 | `overestimated` |
| `rough` | 大らか直感型 | 上記以外 | `volatile` |

タイプの文言（`tagline` / `description` / `badgeColor`）は `SENSE_TYPES`（`src/data/quizMaster.ts`）に定義している。

## 5. 回答分布（10分割ヒストグラム）

`generateDistribution()` が、設問ごとに10個のビンを作る。

1. **範囲の決定**
   - 下限: `min(T×0.5, A×0.85, 平均×0.85)`
   - 上限: `max(T×1.5, A×1.15, 平均×1.15)`
2. **ステップ幅**: `(上限 - 下限) / 10` を「1・2・5・10 × 10^k」のキリの良い値に丸める（最小1円）。
3. **開始点**: 下限をステップ幅で切り捨てた値（最小1円）。
4. **ビン**: 開始点からステップ幅ごとに10個作る。最後のビンは上限なし（`max = Infinity`）。
   - ラベル: 先頭は `〜{開始点+ステップ}円`、末尾は `{min}円〜`、それ以外は `{min}円`。
5. **母集団**: D1 にあるその設問の直近500件に、今回の回答を加えたもの（モックは使わない）。各ビンの `count` と `percent` を出す。
   - ここでの「平均」は、今回の回答を含めた全回答の平均（既存回答がなければ自分の回答）。
6. **フラグ**: 各ビンに `hasUserAnswer` / `hasActualPrice` / `hasAverageExpected` を立てる。

注意点として、最初のビンより下の値（開始点未満）はどのビンにも入らない。

### 5.1 表示ルール（面1）

| 該当 | 色 |
| :--- | :--- |
| あなたの回答 | コバルトブルー |
| 正解（公的相場） | リーフグリーン |
| 全体平均 | マスタードイエロー |
| 該当なし | ニュートラルグレー |
| 複数が同じビンに重なる | 該当色の斜めストライプ（`repeating-linear-gradient(45deg, …)`） |

バーの先端には割合（%）だけを表示し、テキストバッジは付けない。

- **レイアウト**: ヘッダー行の左にタイトル「全体の回答分布」、右に凡例（回答 / 正解 / 平均値 / 重なり）を置く。グラフ全体は 290px の固定枠に収める（10行は高さ方向に均等配分）。
- **目盛り（縦グリッド線）**: 0% を基準線（実線）とし、目盛りの最大値までを4等分した位置に点線を引く。グラフ下に目盛りラベルを置く（幅540px以下では両端のみ）。
- **目盛りの最大値**: 最大ビンの割合を20%刻みで切り上げた値（20〜100%）。棒の長さは「割合 / 目盛りの最大値」で、グリッド線と一致する。

## 6. 1単位プロット（面2）

- `rawAnswers` を1円単位で集計し、回答値ごとの人数を縦棒で表す。X軸は「回答があった金額」と「あなたの回答・正解・平均（四捨五入）の金額」を昇順に並べたもの。
- パネル・凡例・配色（回答=青 / 正解=緑 / 平均値=黄 / 重なり=ストライプ / その他=グレー）は面1と共通（`getBarColorClass()` を共有）。
- **目盛り（横グリッド線）**: 0人を基準線（実線）とし、目盛りの最大値までを4等分した位置に点線を引く。目盛りの最大値は、最大人数を4の倍数に切り上げた値（最小4）。各棒の上に人数を表示する。
- 回答0人の基準価格（正解や平均など）は、基準線上の高さ5pxのマーカーで位置だけ示す。
- 金額の種類が多い場合は、1列48pxを下限として横スクロールにする（Y軸ラベルは左に固定）。
- メトリクスは、あなたの回答、正解、全体平均、中央値の4つ。

## 7. 物価推移（面3）

- 4点（`pastPriceYear`（2020年）→ 2022年 → 2024年 → 2026年）の折れ線を描く。
- **中間年の価格は実データではなく補間値**である。
  - 2022年 = 過去価格 + 差分 × 0.28
  - 2024年 = 過去価格 + 差分 × 0.72
- 軸・グリッド線・ラベルは面2（`.vplot-*`）と共用する。各地点のX座標は、4等分した列の中央（X軸ラベルの中央）。
- **目盛り**: 推移幅を約3目盛りに収める「キリの良い」幅（1・2・5×10^k）で4等分し、最小〜最大がすべて入るまで幅を広げる。推移がない（全期間同額）場合は、価格の5%程度の幅で、価格が中ほどに来るようにする。全100問で、推移が描画高さの25〜75%（中央値57%）を使うことを確認済み。
- **地点の選択**: 各地点は押せるボタン（当たり判定28px）。押すと、その時点の価格を黒い吹き出しで「2022年 690円」「現在 720円」の形で表示する。初期表示は現在（2026年）。上部に余裕がない地点では吹き出しを下側に出し、左端・右端の地点ではグラフ枠内に収まるよう寄せる。
- あなたの回答や世間平均は線に描かず、メトリクス欄に数値で出す。
- 幅640px以下では、X軸ラベルの「年」を省く（吹き出しには「年」付きで表示）。
