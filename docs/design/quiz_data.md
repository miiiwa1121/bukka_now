## 2. スコアリングアルゴリズム

各問のスコア（$S_i$、$0 \le S_i \le 100$）は、回答値 $A_i$ と正解値 $T_i$ の相対誤差率 $E_i = \frac{|A_i - T_i|}{T_i}$ から算出します。

$$S_i = \max\left(0, \min\left(100, \text{round}\left(100 \times \left(1 - \frac{E_i}{0.4}\right)\right)\right)\right)$$

総合スコアは出題全 $N$ 問の平均値：

$$\text{TotalScore} = \text{round}\left(\frac{1}{N} \sum_{i=1}^N S_i\right)$$

---

## 3. 上位何%スコア（パーセンタイル）算出

正規分布モデル（平均 $\mu = 65$、標準偏差 $\sigma = 16$）に基づく標準正規累積分布関数（CDF）より上位パーセントを計算：

$$z = \frac{\text{TotalScore} - \mu}{\sigma}$$
$$\text{TopPercentile} = \max(0.5, \min(99.5, \text{round}((1 - \text{CDF}(z)) \times 100 \times 10) / 10))$$

## 4. 全体回答分布棒グラフ（ヒストグラム）仕様

各問につき、正解価格 $T$ を基準とする5つの価格帯区間（ビン）を設定し、全ユーザーの回答度数を集計・可視化します。

| ビン | 価格帯範囲 | 意味 |
| :--- | :--- | :--- |
| Bin 1 | $0 \le A < 0.75 \times T$ | 大幅に安価と見積もった層 |
| Bin 2 | $0.75 \times T \le A < 0.92 \times T$ | やや安価と見積もった層 |
| Bin 3 | $0.92 \times T \le A \le 1.08 \times T$ | 適正相場・正解ゾーン（正解が含まれる） |
| Bin 4 | $1.08 \times T < A \le 1.30 \times T$ | やや高値と見積もった層 |
| Bin 5 | $1.30 \times T < A$ | 大幅に高値と見積もった層 |

各バーに全ユーザーの比率（%）および件数を表示し、該当するバーに「あなたの選択」「正解」のインジケーターをハイライト表示します。

## 5. 物価感覚タイプ分類（絵文字不使用）

| タイプ名 | 判定条件 | 講評 |
| :--- | :--- | :--- |
| **リアルタイム相場マスター** | $\text{TotalScore} \ge 80$ | 誤差が極めて少なく、最新相場を正確に把握。 |
| **過去価格タイムスリップ型** | $\text{TotalScore} < 80$ かつ $\text{Bias} \le -0.08$ | 数年前の相場記憶で止まっており安く見積もりがち。 |
| **インフレ過敏型** | $\text{TotalScore} < 80$ かつ $\text{Bias} \ge +0.08$ | 報道等の影響で過度に高く見積もりがち。 |
| **大らか直感型** | 上記以外 | 品目ごとにブレがあるマイペース派。 |
